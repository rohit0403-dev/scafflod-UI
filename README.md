# HarborHunt

HarborHunt is a clean search UI for discovering visual inspiration across nature, travel, and city scenes. I chose a sticky, editorial header and a four-chip quick-pick row so users can scan familiar topics without extra friction. The warm sand palette and a dark-mode media query make the design feel different from the reference while keeping it readable in low-light settings. The results grid is intentionally left empty as a ready-made target for later search results.
